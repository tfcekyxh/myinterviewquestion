## 线上报错排查：keypoints 批量 502（2026-10-19 13:20）
- 用户报控制台 `/api/keypoints/83~86` 连续 502，TTS `/85/a` 503（TTS 503 是预期：服务端 TTS 未配置，前端自动退回本机朗读）。
- 根因：**快速翻卡每题立即打一次 LLM**，突发流量把智谱免费档额度打爆。直接打官方接口验证：1302「账户频率限制」与 1305「模型过载」交替，按分钟限流，冷却 75s 仍在 429。
- 修复：前端 keypoints 自动生成加 **600ms 防抖 + AbortController**（停在某题才生成，翻走取消）；server/llm.js 重试退避 `BACKOFF_MS` 1000→2500（熬过按分钟窗口）。`fetchKeyPoints` 加 `signal` 参数。Review 页同样改。
- 测试：Recite/Review 测试改等待「要点文本」而非「回答重点」标题（标题常驻，不等数据）；3 个 keypoints 测试耗时 ~600ms 印证防抖生效。192 web + 4 server 全过，构建过。重发两次。
- 结论：防抖消除「批量 502」突发流（用户主诉）；免费模型高峰仍可能单题 502（模型侧），fail-soft + 重试。根治需换付费模型或整库预生成。已跟用户说明并给两选项。
